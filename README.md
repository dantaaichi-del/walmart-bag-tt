# 沃尔玛购物袋 · TT 三件套 v0.3.0-tt.1

为 TauriTavern 2.4.0（截图构建 fff9af0333be）整理的前端扩展。一份仓库、一个扩展入口，购物袋中打开巧克力播放器、午夜男高、小蝴蝶手机。

免费分享，请勿倒卖、请勿去署名二次发布。

## 安装

安装地址（复制到 TT 的「安装扩展」输入框）：

```text
https://github.com/dantaaichi-del/walmart-bag-tt
```

1. 先备份重要TT数据。若已装独立的购物袋、巧克力、午夜男高或小蝴蝶，先在扩展管理里停用独立版本，避免重复入口；不要清空数据。
2. 在 TT 顶部打开「扩展」，进入「安装扩展」。
3. 粘贴上面的仓库地址，安装到当前用户。
4. 安装完成后重新启动 TT。
5. 点击屏幕上的沃尔玛购物袋，应该能看到巧克力、午夜男高、小蝴蝶三个图标。

不需要 Termux、Node.js、FFmpeg 或额外服务器。不要运行旧ST包的安装脚本，不要将这个ZIP导入预设、角色卡或数据迁移。

## 三个插件怎么用

### 巧克力播放器

- 点购物袋 → 巧克力 →「＋现代音频」或「＋古风音频」，选择手机里的普通 MP3、M4A 等音频。支持多选，单首上限100MB。
- 点歌曲旁的「▶」播放；「编」改歌名和标签，「删」删除曲目。
- 支持顺序、单曲循环、随机播放。实际支持哪些音频编码，以手机WebView能否解码为准；优先使用普通MP3。
- 音频文件和歌名保存到 TT 的原生扩展存储；读取当前播放歌曲时才生成临时音源地址，聊天存档里不塞音频字节。
- 本版不提取视频音轨，不解密QQ/网易云加密文件，不提供原Termux双机曲库同步。
- 原版巧克力浏览器IndexedDB中的旧歌不会被本版自动删除，也没有自动迁入；本版首次使用请重新导入本机音频。

### 午夜男高

- 搜索当前聊天、整条或选段收藏，支持分类、标签、备注和JSON备份。
- 保存后确认显示「已保存到 TT 并核对」。收藏使用 TT 已实现的文件上传、读取和核对接口。
- 如果显示「仅暂存本机」，请先重试或备份JSON，不要把未核对的暂存当成保存成功。
- 本版搜索沿用插件原来的当前聊天上下文，不宣称替代TT的原生全文检索或覆盖所有虚拟化历史。

### 小蝴蝶手机

- 在有角色的聊天中点购物袋 → 小蝴蝶。微信、微博、群聊、朋友圈、头像、表情、匿名树洞、共同歌单等沿用v1.5.1。
- 音乐 →「读取本机曲库」，可读取巧克力导入的歌曲；小蝴蝶内上传音频也写入同一本机曲库。
- 手机剧情内容保存到当前 TT 聊天的元数据。没有原Termux双机同步轮询，也不会提示用户去安装Node同步服务。
- 发消息、刷新NPC内容等生成操作使用朋友自己配置的酒馆API。浏览、收藏和本机音乐播放不请求模型。

## 数据和更新

购物袋长按进入设置，可移动位置、调大小、调透明度、隐藏原悬浮入口、单独开关三个入口。

更新扩展代码不会主动删除聊天、角色卡、收藏或本机曲库。清除TT应用数据或卸载应用仍可能丢失本机数据；重要内容请自行保留备份和原音频文件。

本包仅含插件代码和原有素材，不包含作者的账号、API密钥、聊天、角色卡、收藏或曲库。

首次安装请依次确认：三个入口能打开 → 导入一首MP3并播放 → 小蝴蝶读取该曲库 → 收藏一段文字并核对 → 重启TT后数据还在。
